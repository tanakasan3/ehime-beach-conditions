# 🌊 Ehime Beach Conditions

Real-time tide, wave, and wind conditions for beaches in Ehime Prefecture, Japan.

## Beaches

- **塩屋海岸** (Shioya Beach) - Near Imabari
- **堀江** (Horie Beach) - Matsuyama coastal area  
- **別府** (Beppu Beach) - South Matsuyama

## Features

- 🌊 Wave height and direction
- 💨 Wind speed (m/s) and cardinal direction
- 🌙 Tide level (meters above mean sea level)
- Auto-refresh every 10 minutes
- Mobile-friendly responsive design

## Data Sources

- Weather data: [Open-Meteo Weather API](https://open-meteo.com/)
- Marine data: [Open-Meteo Marine API](https://open-meteo.com/en/docs/marine-weather-api)

## Live Site

👉 **[View Live](https://tanakasan3.github.io/ehime-beach-conditions/)**

## Note

Coordinates are approximate. Marine data resolution is ~8km, so conditions may vary at actual beach locations. Always check local conditions before entering the water.
